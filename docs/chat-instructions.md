# チャットの報告

Stopフックで止められたときは、前の返答が表示済みなので、全文を書き直さず足りない点だけを短く書きます。通知の回に質問を置き直す場合を除き、表示済みの質問が有効なままなら再掲せず、質問の内容を変えたときか指摘が質問自体に向いたときだけ、質問と選択肢を最後に1回置きます。判断の記録が要る回は、その行だけを足します。
